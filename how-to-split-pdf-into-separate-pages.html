How to Split a PDF Into Separate Pages or Extract Page Ranges

Published October 13, 2026 · JanjuaPDF guides

Split a PDF now

A long PDF is not always convenient. You may need only the invoice on page 4, one chapter of a scanned book, or each page as its own file so you can send them to different people. Splitting a PDF solves all of these, and you can do it in your browser without installing anything.

Two ways to split

  • Every page as a separate PDF. You get a ZIP file with one PDF per page. A 10-page document becomes 10 small files.
  • One PDF from a page range. You type the pages you want, and you get one new PDF that contains only those pages.

Step by step: extract only some pages

  1. Open the Split PDF tool.
  2. Choose your PDF file.
  3. Pick the range mode.
  4. Type the pages you want. For example 1-3,5,8-10 means pages 1 to 3, page 5, and pages 8 to 10.
  5. Press Run and download the new PDF.

Step by step: one file per page

  1. Open the Split PDF tool and choose your file.
  2. Pick the mode that makes every page a separate PDF.
  3. Press Run. A ZIP file downloads.
  4. Open the ZIP on your computer to find one PDF for each page.

How to write a page range

  • A single page: 4
  • A group of pages: 2-6
  • Several parts at once, separated by commas: 1-3,7,10-12

The first page of the document is page 1, even if the printed number on the page is different. If you type a page that does not exist, the tool will tell you.

Split or delete: which one should I use?

They give a similar result from two directions. Use Split when you know which pages you want to keep. Use Delete PDF Pages when you know which pages you want to remove. Our guide How to Delete Pages From a PDF explains the second way.

Good to know

  • Your original file is not changed. You always get new files.
  • If you need the pieces back together later, use Merge PDF.
  • The pieces are usually smaller than the full document, which can help when a file is too big to email.

Is it safe?

Yes. Splitting runs inside your own browser, so your PDF is not uploaded to our servers.
