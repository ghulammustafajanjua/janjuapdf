How to Make a PDF Smaller for Email (Free, No Upload)

Published October 11, 2026 · JanjuaPDF guides

Compress a PDF now

You attach a PDF to an email and get an error: the file is too large. Many email services accept attachments only up to roughly 20 to 25 MB, and some websites and job portals allow far less, sometimes just 1 or 2 MB. The exact limit depends on your provider, so check it before you start. This guide shows how to shrink a PDF in a few clicks without installing anything.

Why are some PDFs so big?

The size of a PDF depends mostly on what is inside it. A document that is only text is usually small. A PDF full of photos, or a scan made by a phone or scanner, is large because every page is basically a big picture. If your file is large, the cause is almost always images.

Step by step: compress a PDF

  1. Open the Compress PDF tool.
  2. Choose your PDF file.
  3. Pick a method (explained below) and, for the Strong method, a quality level.
  4. Press Compress PDF. The tool shows the size before and after.
  5. Download the new file and check that it still looks right before you send it.

Filling in an online form with a strict limit such as 100 KB or 200 KB? Use the Target size option and follow How to Compress a PDF to 100KB or 200KB.

Strong or Light: which method should I use?

Strong

Strong turns every page into a compressed image and builds a new PDF from those images. This gives the biggest saving, and it works well for scanned documents, photo-heavy files and brochures. The trade-off is important: text can no longer be selected or searched, and links and form fields are lost.

Light

Light keeps your text, links and structure and only repacks the file. The saving is usually small, and for many PDFs it will not help at all. Use it when you need to keep the text selectable and the file only needs a little trimming.

Which quality level?

  • Balanced is a good starting point for most files.
  • Smallest file gives the strongest reduction, but fine print can look softer.
  • Best quality keeps pages sharper, with a smaller saving.

Tip: start with Balanced. If the file is still too large, try Smallest. If the result looks too blurry, go back to Best quality.

What if the file does not get smaller?

Some PDFs are already well compressed, and trying to shrink them again can make them bigger. In that case the tool tells you instead of giving you a larger file. Here are other ways to cut the size:

  • Remove pages you do not need with Delete PDF Pages.
  • Send the document in parts. Use Split PDF to make two smaller files.
  • Try the other method. A file that does not shrink with Light often shrinks with Strong.

Good habits

  • Keep your original. Strong compression is not reversible. Save the compressed file under a new name.
  • Compress once. Compressing the same file again and again lowers quality each time.
  • Look at every page before sending, especially signatures, stamps and small numbers.

Is it safe?

Yes. The compression runs inside your own web browser, so your PDF is not uploaded to our servers. That matters for documents like ID copies, contracts and invoices.
