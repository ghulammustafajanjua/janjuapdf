How to Add Page Numbers to a PDF (Free, Any Start Number)

Published October 13, 2026 · Updated October 24, 2026 · JanjuaPDF guides

Add page numbers now

Page numbers make a long document easier to read, print and discuss. "Please look at page 12" only works when every page has a number. If your PDF has none, for example after you merged several files, you can add them in your browser.

Step by step: add page numbers

  1. Open the Add Page Numbers tool.
  2. Choose your PDF file.
  3. Pick where the number goes: bottom center, bottom right, bottom left or top center.
  4. Choose the number to start from (normally 1).
  5. Press Run, download your numbered PDF and scroll through it once to check.

Which position is best?

PositionBest for
Bottom centerReports, assignments, letters and anything printed on both sides of the paper. It stays in the same place on left and right pages.
Bottom rightDocuments read on screen or printed on one side only.
Bottom leftPages where the bottom right already has a logo, stamp or signature.
Top centerForms and scans where the bottom of the page is full.

Do the work in the right order

  1. First merge all your files into one PDF.
  2. Then fix the page order with Organize PDF, and remove pages you do not need with Delete PDF Pages.
  3. Add page numbers last, so the numbers match the finished document.

If you number first and then delete or move pages, the numbers will be out of order and you will have to start again from your original file.

Starting from a number other than 1

Use the Start from number box when your PDF continues another document. If part one has 20 pages, start part two at 21 and the numbering continues without a gap. This is useful for chapters of a thesis that were written in separate files, or for adding extra pages to a bundle that was already numbered.

How to leave the cover page without a number

Many reports and theses have a cover page that should not show a number, while the next page shows "2". The tool numbers every page in the file, so use this simple trick:

  1. Use Split PDF in range mode to save page 1 (the cover) as one file and pages 2 to the end as another.
  2. Add page numbers to the second file with Start from number set to 2.
  3. Merge the cover and the numbered pages back together.

Common uses

  • University assignments and theses that require numbered pages.
  • Document bundles for visa, job or bank applications, so the person checking them can say "page 7 is missing a signature".
  • Meeting papers and contracts, so everyone discusses the same page.
  • Merged scans, where it is easy to lose track of the order.

Frequently asked questions

Can I add page numbers to a scanned PDF?

Yes. The number is placed on top of each page, so it works on scans and photos as well as normal PDFs.

Can I skip the first page?

Yes, with a small workaround: split off the cover page, number the rest starting from 2, then merge them back together. The steps are explained above.

Can I use Roman numerals or "Page 1 of 10"?

No. The tool adds simple numbers (1, 2, 3...). For other styles, edit the original document in Word or Google Docs and export it to PDF again.

Can I remove page numbers later?

Not easily, because the number becomes part of the page. Always keep your original file and save the numbered version as a copy.

Is my PDF uploaded?

No. The numbers are added inside your own browser, and your file is not sent to our servers.
