How to Merge PDF Files Into One (Free and Private)

Published October 11, 2026 · JanjuaPDF guides

Merge PDF files now

Job applications, bank documents, school forms and invoices often arrive as many separate PDF files. Sending one combined file is cleaner and easier to read. Merging is the process of joining several PDFs into one document, and you can do it in your browser in under a minute.

Step by step: merge PDF files

  1. Open the Merge PDF tool.
  2. Click the box and choose two or more PDF files, or drag them in.
  3. Look at the list. Use the up and down arrows next to each file to put them in the order you want.
  4. Press Merge PDF.
  5. Download merged.pdf and scroll through it once to check the order.

Getting the order right

The merged file follows the order of your list from top to bottom. Pages inside each file keep their own order. If you notice a mistake after merging, you do not need to start over. Use Reorder PDF Pages to change the order of pages in the finished file.

Common problems and how to fix them

The file says it is password protected

PDFs that are locked with a password cannot be merged until they are unlocked. Open the file with its password in your PDF viewer, save or print it to a new PDF without the password, and use that copy.

Pages look like different sizes

Each page keeps its original size, so a mix of A4, letter and phone scans will look uneven when you scroll. This is normal. If it bothers you, use the same page size when you create the source files.

The merged file is too big

The result is about as large as all the files added together. If you need to email it, use Compress PDF afterwards.

I only need a few pages from each file

First use Split PDF in range mode to pull out just the pages you want, then merge the smaller files.

Handy ways to use merging

  • Job applications: CV, cover letter and certificates in one file.
  • Expenses: every receipt for the month in one document.
  • Studying: lecture notes and past papers together.
  • Photos of documents: turn pictures into a PDF with Images to PDF, then merge them with your other files. Our guide How to Convert Photos to PDF on Your Phone shows every step.

Is it safe?

Yes. Merging happens inside your browser, and your files are not uploaded to our servers.
